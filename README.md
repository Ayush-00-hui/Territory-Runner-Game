**Territory Runner** is a visually stunning, location-based run tracking application built with Flutter. Track your runs, claim blocks, and keep your streak alive with minimal noise and maximum momentum.

## ✨ Features

- **📍 Live Location Tracking:** Uses `geolocator` and `flutter_map` to track your current position on the map.
- **🎨 Premium UI:** A sleek, dark-themed interface inspired by modern fitness apps with micro-animations and glowing accents.
- **🏃‍♂️ Runner Profiles:** Track total distance, level up with XP, and earn badges.
- **🗺️ Territory Claiming:** Claim areas based on your running routes.

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Android Studio / Xcode

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Ayush-00-hui/Territory-Runner-Game.git
   ```
2. Navigate into the directory:
   ```bash
   cd Territory-Runner-Game
   ```
3. Install dependencies:
   ```bash
   flutter pub get
   ```
4. Run the app:
   ```bash
   flutter run
   ```

## 🛠️ Tech Stack

- **Framework:** Flutter
- **Language:** Dart
- **Packages:** `flutter_map`, `geolocator`, `latlong2`
